# COD Pattern 热点战

供 Minecraft 1.20.1、Forge 47.4.0、Java 17 使用的独立 CDP 附属。客户端和服务端均需安装热点附属、COD Pattern **0.9.0b** 和本体要求的 TaCZ。构建使用 Modrinth 发行 ID `i2KWW5XO`，联调使用 TaCZ 1.1.8-hotfix2。[COD Pattern 发行页](https://modrinth.com/mod/cod-pattern/version/i2KWW5XO)

## 部署地图

需要权限等级 2。在创造模式的 CDP 工具栏中取出淡紫色的「热点部署仪」，物品 ID 为 `codpattern_hardpoint:deployment_tool`。

1. **创建地图。** 主手拿部署仪，左键、右键分别点击地图边界的两个对角方块。按 **Ctrl + 右键** 打开面板，输入地图名并点击「创建地图」。编辑已有地图时，用面板中的左右箭头切换地图。
2. **设置出生点。** 在面板选择「红队出生点」或「蓝队出生点」，关闭面板，左键点击地面，工具会把该方块上方的位置和你的朝向存为出生点。两队各至少需要一个出生点。多人地图可为每队标记多个分散的位置。同样可以选择「离场点」并标记赛后的返回位置。
3. **绘制热点。** 选择「热点」，关闭面板，用左键和右键标记两个对角。按 **Ctrl + 右键** 返回，填写热点名并保存。选择「＋ 新增热点」可继续画下一个，至少需要两个。两个角点同高时，玩家站在选中地板上即可占点。两角高度不同时，区域包含从较低角到较高角的所有方块，适合分层建筑。
4. **确定轮换顺序。** 用热点行的箭头选中目标，点「前移」或「后移」。手持部署仪可查看编号与边框。点「验证地图」检查布局。对局按 P1、P2、P3 等顺序循环，保存的热点、名称和顺序会在世界重启后恢复。

## 对局规则

玩家从 CDP 大厅加入「热点战」，选择阵营并准备。每队最多 6 人，两队都有人且全部准备后，可以发起开始投票。全员同意后，房间界面关闭，玩家在原地倒计时 **10 秒**。最后 3 秒画面逐渐变黑，随后双方传送到各自出生点，领取所选 CDP 背包。接下来的 **20 秒**为准备阶段，移动、开火与投掷均锁定。准备结束即可行动，比赛时钟启动。再过 **5 秒**，首个热点开放。

| 活动热点内的队员 | 团队得分 | 比赛总倒计时 |
| --- | --- | --- |
| 只有红队或只有蓝队 | 独占方每秒得 1 分，人数不会加速 | 暂停 |
| 双方都有人 | 双方停分 | 暂停 |
| 无人 | 双方停分 | 继续 |

热点轮换参考《使命召唤：黑色行动 6》。每个热点持续 **60 秒**，最后 **10 秒**预告下一个热点。热点自身的时钟在独占、争夺和空置时都会继续。只有本房间内存活的队员可以占点。个人占点时长按每名参与独占的队员分别累计。[官方热点模式指南](https://www.callofduty.com/guides/blackops6/modes/call-of-duty-guides-black-ops-6-multiplayer-mode-guide-hardpoint)

先到 **250 分**的一队获胜。5 分钟比赛总倒计时耗尽时，分高者获胜，同分平局。投票通过后若一队全部离房，留场队获胜。阵亡队员在 3 秒后重生，重生时领取 CDP 当前选中的背包。战斗中预选的新背包在下次出生时生效。

结算沿用内置模式的胜负动画与双栏战绩表。表中显示胜负原因、双方最终比分、个人占点时长与击杀死亡数据，每队优先按占点时长排名。结算结束后可在同一房间重新准备。

## 构建与验证

在本目录使用 Java 17 执行以下命令。

```powershell
.\gradlew.bat build
.\gradlew.bat runGameTestServer
```

`build` 会运行逐 tick 的规则测试并生成 `build/libs/codpattern-hardpoint-0.1.1.jar`。Forge GameTest 在独立测试世界验证部署仪选区与排序、存档重载、大厅开局、计分、重生换包和结算。构建默认识别同级 CDP 工程的同版发行 JAR 并检查官方 SHA-512，也可以通过 `-PcodpatternJar=<路径>` 指定该发行包。缺少本地发行包时，Gradle 使用 Modrinth Maven 的固定版本。
